**Separate approval required after exact-R hosted CI passes.** Recheck tag
absence, owner identity and package permissions. Present R, proposed annotated

The configured `Docker release` workflow checks owner actor/triggering actor,
annotated stable tag, exact source/ref/version, main ancestry, no backwards
`latest`, successful main-push CI for the same commit, and package continuity.

4. After that approval, pin verified `ghcr.io/seakleangnhak/harbor@sha256:DIGEST`, preserve

   initial container memory**, existing 512 MiB Go soft limit and two CPUs. Keep

5. Verify authentication, readiness, folders, old-file SHA-256/ranges, a generated
   new upload/download, session persistence/restart and a post-upgrade backup.
   Record actual results without printing credentials.
6. For rollback, drain/cancel new work, stop candidate and preserve newer references

   Telegram reconnect and old-file checksums; never run old binary against pending

   installation/archive until newer files have an explicit recovery/export plan.

Do not delete volumes, keys, backups or Telegram messages during upgrade/rollback.

## Operating limits and status

1 GiB is recommended initial memory, not guaranteed headroom. 768 MiB passed
bounded tests without proven spare capacity; both budgets reached cgroup ceilings
through file cache. Budget active staging/cache, metadata, crash leftovers,
backups and fresh restore space; no total disk minimum/hard quota is qualified.
Monitor both volume and backing host. Shipped Compose remains at 768 MiB until
operator explicitly configures the documented deployment setting.

Telegram is an external dependency with no guaranteed independent content
durability. Recovery archives preserve local state/references, not a mirror of
remote ciphertext. Keep independent protected content copies. Live cross-DC,
physical iOS, multi-day operation and cold live-browser media latency remain
incomplete. No independent security audit or public-internet qualification is
claimed; see [known limitations](KNOWN_LIMITATIONS.md).
