# Community code of conduct

Harbor welcomes thoughtful contributions regardless of background, experience, identity, or location. Be respectful, assume good intent when reasonable, and critique ideas or code rather than people.

## Expected conduct

- Use clear, constructive language and accept good-faith feedback.
- Respect different experiences and accessibility needs.
- Keep discussion relevant, credit others' work, and follow applicable licenses.
- Protect contributors' privacy. Never publish another person's contact details, credentials, private files, or installation information.

Harassment, threats, discriminatory attacks, sexualized conduct, doxxing, deliberate disruption, and repeated unwanted contact are not acceptable. This applies to project issues, pull requests, discussions, reviews, and spaces where someone represents Harbor.

## Reporting and moderation

Report concerns privately to repository maintainers through an available private reporting channel. If none is available, request a private contact route publicly without names, allegations, screenshots, or other sensitive details. Security vulnerabilities follow [SECURITY.md](SECURITY.md).

Maintainers may edit or remove harmful content, lock discussions, limit participation, or block accounts. Responses should match the severity and pattern of conduct. Maintainers should preserve privacy, explain moderation decisions where safe, and recuse themselves when personally involved. Affected participants may request review by another available maintainer; no independent appeals body is promised.

This policy is original project guidance. It does not replace platform reporting, emergency services, or legal remedies.
