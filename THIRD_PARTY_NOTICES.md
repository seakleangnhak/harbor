# Third-party notices

Harbor's original source, documentation, demonstration screenshots, and original branding are licensed under the [MIT license](LICENSE). Third-party components keep their own terms. Retain this file and the original notices when distributing Harbor binaries, images, or bundled browser assets.

This inventory covers the Go modules linked by the `telegram` build of both shipped commands, the Go runtime, and locked non-development browser packages. Some packages cover optional/browser support code and may be tree-shaken. Optional native Node canvas bindings are not part of the browser bundle or production image. Development/build tools are installed from their own packages and retain the licenses distributed with them; the lockfiles identify their exact versions. This is a source/license inventory, not legal advice or an independent compliance audit.

## Assets and provenance

- Harbor's README SVG branding is original project artwork. Application typography uses system fonts; no Apple, Microsoft, or other system font files are redistributed.

Liberation Sans **1.07.4** is GPL-2.0 with the **Liberation font exception**, not SIL OFL. Its full exception and GPL text are retained in `web/public/pdf-font-notices.txt` and below.
